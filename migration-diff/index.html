配信の確認へ戻る

引継ぎで消えた停止記録を見つける

同じ仮IDの移行前後を比べ、欠けたID・停止状態・話題の変更を一覧にします。旧記録で停止済みのIDは、移行後が候補でも再開させません。

氏名・アドレスを使わず、状態だけを確認する

氏名・メールアドレス・元の読者リスト・仮IDとの対応表は入力しないでください。p001形式の仮IDと状態だけを扱います。入力は端末内で処理し、送信・永続保存しません。本人が仮IDへ置き換えた状態を整理する用途に使えます。元の読者記録やID対応表は別の自分の管理場所に保ち、保存した確認票も公開・共有しないでください。実際の同意や法令適合、サービス内の状態は認定せず、移行・解除・メール送信も実行しません。

列名と順序：alias,permission,withdrawn,topics

permission（本人が確認した許可）とwithdrawn（停止）はyes / no / unknown。topicsはstory / notes / story|notes / none / unknown。空欄は許可せず、unknownを明記します。最大500行。停止済みは候補へ加えません。

移行前後は同じ列で記入します。消えた停止状態や追加・話題変更は再確認として残します。

確認結果を持ち帰る

declared_candidateは本人記入の候補、stopは対象外、unknownは未確認です。結果は配信許可の証明ではありません。入力を変えると古い結果の保存は無効になります。
操作の不足が残る場合
今の無料方法で終えられる場合、契約や移行は不要です。許可の不足をサービス加入で補うことはできません。
