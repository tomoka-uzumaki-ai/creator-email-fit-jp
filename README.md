# 自作コンテンツの配信を、今の無料方法で終えられるか確認する

短編や制作ノートを、希望する読者へ送りたい作者向けの無料チェックシートです。登録者数と配信通数を分け、希望別の宛先・解除・担当交代を整理します。今の無料サービスで必要な作業が完了するなら、新しい契約や移行は不要です。

[人数・通数と希望別配信を確認する](https://tomoka-uzumaki-ai.github.io/creator-email-fit-jp/)

## 困っている作業から始める

1. [登録総数と今回の対象・除外・未確認を分ける](https://tomoka-uzumaki-ai.github.io/creator-email-fit-jp/audience-readiness/)。
2. [配信回数から月間通数を整理する](https://tomoka-uzumaki-ai.github.io/creator-email-fit-jp/send-plan/)。テスト・追加配信も含めます。
3. [現在の無料プランで希望別配信ができるか確認する](https://tomoka-uzumaki-ai.github.io/creator-email-fit-jp/#calculator)。本人の配信希望と解除済みの除外を確認してから、必要機能を比べます。

集計値だけを入力します。読者名・メールアドレス・ログイン情報は不要です。入力内容を外部送信・自動保存する機能、読者リストの収集、登録受付、実際の配信、契約代行はありません。結果や空欄の確認票は、自分で保存して管理してください。

## Kit・MailerLiteの条件を読む場合

チェックシート内のKit・MailerLiteへのリンクは、通常の公式リンクです。紹介料を伴う広告リンクではありません。無料範囲、契約、更新・解約条件は現在の自分のアカウントと公式画面で確認してください。資料の条件と合成例は、実際のアカウント動作の保証ではありません。

[Kit公式料金](https://kit.com/pricing) · [MailerLite公式料金](https://www.mailerlite.com/pricing)

## 日本語の電話支援が必要な場合

今の無料運用で困っている操作が残り、日本語の電話相談が必要な方は、[相談したい作業を一つに絞る](https://tomoka-uzumaki-ai.github.io/creator-email-fit-jp/phone-support-brief/)ところから始められます。

**広告について：** [める配くんの費用・読者引継ぎ確認票](https://tomoka-uzumaki-ai.github.io/creator-email-fit-jp/japanese-mail.html)にはA8.netのアフィリエイト広告が含まれます。紹介先への申込み等が条件を満たすと、運営者が紹介料を受け取る場合があります。契約を選ぶ前に、同じ確認票の次の項目を読んでください。

- [契約総額・最低期間・試用条件](https://tomoka-uzumaki-ai.github.io/creator-email-fit-jp/japanese-mail.html#cost)：月額に加え、初期費用・契約期間・税・追加費用を確認。[自分の人数・通数・期間で比較する無料ツール](https://tomoka-uzumaki-ai.github.io/creator-email-fit-jp/contract-cost/)もあります。
- [読者情報の取扱いと公表された調査報告](https://tomoka-uzumaki-ai.github.io/creator-email-fit-jp/japanese-mail.html#data)：配信先情報が外部取得されたことを公表した公式報告と、現行対策へのリンクを確認できます。当方による安全性の保証・独立監査ではありません。
- [不足が残る場合の広告リンクと申込条件](https://tomoka-uzumaki-ai.github.io/creator-email-fit-jp/japanese-mail.html#next)：無料運用で完了する場合は移行不要です。

このチェックシートと比較票の利用は無料です。リンク先サービスの契約費用は、その提供会社へ支払う別の料金です。電話支援の対象プラン、税込総額、更新・解約・返金、試用後の扱いは申込画面で確認してください。申込み・支払い・読者移行・メール配信は自動実行しません。

配信許可と解除状態を引き継げないまま読者リストを移さないでください。最初の確認は、自分宛ての架空テストから行います。この資料はサービス提供会社の公式資料・認定・提携サービスではありません。
